AQL 抽检标准：定义、执行与避坑

发布 2026-11-07 · 更新 2026-11-07

AQL 全称 Acceptable Quality Limit，中文叫接收质量限，对应国标 GB/T 2828，是全球通用的计数抽样检验标准。本页讲清它的底层逻辑、执行流程与常见误区，不用死记硬背。

一、AQL 到底是什么

官方定义：当一个连续系列批被提交验收抽样时，可允许的最差过程平均质量水平。

通俗理解：AQL 是供需双方提前约定的「生产过程质量及格线」。

  • 它不是「单批产品最多允许有百分之多少不良」，而是要求生产方的长期过程平均不良率低于这个值。
  • 只要生产过程稳定在 AQL 以下，绝大多数提交批次都会被接收。
  • 一旦批次质量明显超过 AQL，被拒收的概率就会大幅上升。

最常见的误解：AQL 2.5 不是说「100 个产品里允许 2.5 个不良」，而是说「如果生产过程平均不良率长期稳定在 2.5% 以内，那么大部分批次都能通过抽检」。

核心认知：AQL 数值越小，质量要求越严格。按 AQL 数值从大到小，要求越来越高：AQL 4.0 ＜ AQL 2.5 ＜ AQL 1.0 ＜ AQL 0.65。

二、三要素与缺陷分级

2.1 三个缺一不可的核心要素

任何一次完整的 AQL 抽检，都必须包含三个要素，缺一个都等于没说清标准：

  1. 批量（Lot）：待检验的整批产品总数量。
  2. 检验水平：决定抽样的严格程度和样本量大小。
  3. AQL 值：双方约定的接收质量限数值。

2.2 缺陷分级

国标按严重程度将不合格分为 A、B、C 三类，对应我们常说的致命、严重、轻微缺陷。不同等级必须匹配不同的 AQL 值。

缺陷等级 定义 常用 AQL 值
A 类（致命缺陷）危及人身安全、违反法规、完全丧失功能AQL 0（零容忍，发现一个即拒收）
B 类（严重缺陷）功能失效、主要性能不达标、严重影响使用AQL 0.65 / 1.0 / 2.5
C 类（轻微缺陷）外观瑕疵、不影响使用的小问题AQL 2.5 / 4.0 / 6.5

具体数值由供需双方在合同或品质协议中约定，上表为行业通用参考。

三、执行流程：六步走完一个闭环

很多人用 AQL 只停留在「查表」这一步。完整的执行是一套从约定到判定、再到动态调整的闭环。

第一步：事前约定规则

抽检前必须先明确三件事，避免后续扯皮：

  • 按严重程度划分缺陷等级，每个等级对应约定的 AQL 值。
  • 约定检验水平：无特殊要求默认用一般检验水平 Ⅱ，在检验成本与鉴别力之间最均衡；质量长期稳定、检验成本高可选 Ⅰ 级；质量要求高、风险大选 Ⅲ 级。
  • 约定抽样类型：分一次、二次、多次抽样。绝大多数常规场景用一次抽样，操作最简单、管理成本最低。

第二步：批量 + 检验水平 → 样本量字码

先在批量范围里找到对应区间，横向对应约定的检验水平，得到一个字母（A 至 R），这就是样本量字码。

常用批量区间与一般检验水平字码对照：

批量范围 一般检验水平 Ⅰ 一般检验水平 Ⅱ 一般检验水平 Ⅲ
2 至 8AAB
9 至 15AAC
16 至 25ABD
26 至 50ACE

91 至 150BDG

例如：批量 800 PCS，约定一般检验水平 Ⅱ，对应字码为 J。

第三步：字码 + AQL 值 → 抽样方案

用样本量字码找到对应行，横向找到约定的 AQL 值，得到三个关键参数：

  • n：需要抽取的样本总数量。
  • Ac（接收数）：样本中不良数 ≤ Ac，整批接收。
  • Re（拒收数）：样本中不良数 ≥ Re，整批拒收。

箭头规则：如果字码与 AQL 的交叉处是箭头，顺着箭头方向找到第一个有数值的 Ac / Re，再沿着这一行往左，读出对应的样本量 n。

第四步：随机抽样与结果判定

抽样原则：必须采用简单随机抽样，从整批产品的不同位置、不同包装箱、不同生产时段中抽取，确保样本有代表性；批量较大时建议按比例分层抽样。禁止专挑外观好的、只从最上面的箱子取样。

判定规则：按缺陷分类分别统计不良数，分别与对应 AQL 的 Ac / Re 对比。只要有任意一类缺陷的不良数 ≥ Re，整批拒收；所有类别不良数均 ≤ Ac，整批接收。

第五步：不合格批的处置

  • 被拒收的批次，可根据实际情况选择全检挑选、返工、降级或报废。
  • 所有不合格品处理完成后，可重新提交检验。
  • 重新提交的批次，默认采用加严检验，且需覆盖所有类型的缺陷。

第六步：执行转移规则，动态调整严格度

这是 AQL 的灵魂，也是大量工厂忽略的一步。国标设置正常、加严、放宽三种检验严格度：

正常 → 加严：正常检验时，连续 5 批、或少于 5 批中有 2 批被拒收，立即转为加严检验（样本量不变，Ac / Re 收窄，判定更严）。

加严 → 正常：加严检验后，连续 5 批全部接收，转回正常检验。

正常 → 放宽：需同时满足三个条件——

  1. 转移得分累计 ≥ 30 分（批接收就加分，拒收直接清零）。
  2. 生产过程稳定。
  3. 负责部门认可放宽检验可行。

转移得分规则：

抽样类型 加分条件 得分
一次抽样，Ac ≥ 2把 AQL 加严一级后再评判，该批仍然接收+3
一次抽样，Ac ≥ 2该批拒收，或加严一级后判不接收重置为 0
一次抽样，Ac = 0 或 1本批直接接收+2
一次抽样，Ac = 0 或 1本批拒收重置为 0
二次抽样第一样本就接收（不用抽第二样本）+3
二次抽样第一样本就拒收，或要抽第二样本才接收重置为 0
多次抽样第一样本或第二样本就接收+3
多次抽样到第三样本及以后才接收或拒收重置为 0

注意：Ac ≥ 2 时不是只要本批接收就 +3 分，必须 AQL 加严一级下也能接收才给 3 分，这点很多人会搞错。

放宽 → 正常：出现 1 批拒收、生产不稳定或有其他异常，立即转回正常检验。

暂停检验：加严检验下，累计 5 批拒收，应暂停抽样检验。供方完成质量整改并验证有效后，才能从加严检验开始恢复。

四、实战示例

已知条件：批量 800 PCS；检验水平：一般 Ⅱ 级；AQL：严重缺陷 2.5，轻微缺陷 4.0。

步骤 结果
查字码批量 501 至 1 200 对应一般检验水平 Ⅱ → 字码 J
查样本量字码 J 对应样本量 n = 80
严重缺陷 AQL 2.5Ac = 5，Re = 6
轻微缺陷 AQL 4.0Ac = 7，Re = 8

结论：从整批中随机抽取 80 个样品，严重不良 ≤ 5 个、轻微不良 ≤ 7 个，则整批接收。

五、六个常见误区

坑 1：把 AQL 当成「整批允许不良率」

AQL 是过程平均质量要求，是对生产方长期质量水平的约定，不是「单批最多可以有多少不良」。抽检是用样本推断整体，本身存在统计风险，单批实际不良率可能高于或低于 AQL。不能说「这批不良率 2.5% 就符合 AQL 2.5」。

坑 2：只说 AQL 数值，不提检验水平

「我们按 AQL 2.5 验货」是非常不严谨的表述。同样是 AQL 2.5，检验水平 Ⅰ、Ⅱ、Ⅲ 的样本量相差一倍多，判定严格度完全不同。完整的标准表述必须包含：批量 + 检验水平 + AQL 值。

坑 3：抽样不随机，选择性抽样

只从托盘最上面、货柜最前面的箱子取样，甚至特意挑外观好的产品，样本就完全没有代表性。样本失去代表性，哪怕抽样方案完全符合标准，抽检结果也没有意义。

坑 4：永远只用正常检验

很多公司从导入 AQL 那天起就只用正常检验。质量下滑时不加严，不良流出风险升高；质量长期稳定时不放宽，白白浪费检验人力。动态调整才是 AQL 的核心价值。

坑 5：所有缺陷用同一个 AQL 值

致命、严重、轻微缺陷都按 AQL 2.5 判定是严重错误。致命缺陷必须零容忍，严重缺陷严格管控，轻微缺陷适当放宽。分级管控、匹配不同 AQL，才能兼顾风险与效率。

坑 6：样本量按批量比例计算

「1000 个抽 20 个，那 2000 个就抽 40 个」是典型错误。AQL 的样本量不是等比例的：批量 100 抽 20 个（20%），批量 10 000 抽 200 个（2%），比例相差 10 倍。这是统计原理决定的——批量越大，相同样本量的推断精度越高。

六、五句话吃透 AQL

  1. 三要素齐全才有效：批量、检验水平、AQL 值，缺一个标准都不完整。
  2. 查表两步就搞定：先找字码，再找 n、Ac、Re；遇箭头顺箭头找数值。
  3. 判定规则很简单：不良数 ≤ Ac 接收，≥ Re 拒收，分缺陷类别分别判定。
  4. 灵魂在于动态调：正常、加严、放宽按规则切换，质量波动及时响应。
  5. 本质是风险共担：AQL 不是零缺陷，是买卖双方都认可的质量风险平衡点。

AQL 不是质量人的「背诵题」，而是管控批量质量的实用工具。搞懂背后的统计逻辑，按标准流程执行，避开常见误区，就能从「只会查表」变成「真正会用」。
